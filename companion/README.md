# Murmur companion apps

Peripheral hardware for Murmur. One directory per device, one shared wire protocol.

```
companion/
  protocol.md        wire protocol v1, the only contract both sides implement
  flipper/           Flipper Zero app (C, built with ufbt)
  android-plan.md    Android companion: planning only, not started
```

## Flipper Zero (phase 1)

Turns the Flipper into a one-button remote for Murmur: press OK to start dictation, press
it again to stop, Up to enhance, Down to accept, Back to dismiss. The map is configured in
Murmur's Settings (page 06 Companion) and pushed to the device, which caches it on the SD
card so the app still shows the right legend while Murmur is closed.

### Build

```sh
pip install ufbt          # once
companion/flipper/build.sh
```

The result is `companion/flipper/dist/murmur_companion.fap`. Copy it to the Flipper's
`apps/` folder, or run `ufbt launch` with the device connected.

### Use

1. Murmur → Settings → Companion → enable, transport USB.
2. Plug the Flipper in with a **data** cable and open Murmur Companion on the device.
3. The status line reads `linked` once the handshake completes.

While the app holds the USB serial port, qFlipper and the Flipper mobile app cannot use
it. Exit the app (hold Back) or unplug to restore normal behaviour.

### Layout

```
application.fam          manifest; fap_version is generated by sync_version.py
src/protocol.{h,c}       parse/format; no Flipper APIs, easy to review
src/link.{h,c}           USB CDC transport with a polled ring buffer
src/config.{h,c}         caches the pushed button map on the SD card
src/murmur_companion.c   app: view port, input, timers, lifecycle
scripts/sync_version.py  mirrors Murmur's version into the manifest and version.h
```

### Limits (phase 1)

- USB only. The Bluetooth serial profile is phase 2; the protocol already supports it.
- The host side of USB is implemented for unix. Windows reports the link as unsupported
  rather than pretending.
- Back long press always exits the app, because that is the platform convention. That is
  why `back_long` is not a configurable action.

## Versioning

The FAP version tracks Murmur's version exactly (`src-tauri/Cargo.toml` is the source of
truth), so `murmur 0.2.2` ships `murmur_companion.fap 0.2.2`. The wire protocol has its
own integer, checked in three files by `scripts/check-protocol-version.mjs`, so a version
skew is diagnosed as a protocol mismatch instead of a mystery.

## CI

`.github/workflows/flipper-build.yml` builds on any change under `companion/flipper/`
and attaches `murmur-companion-vX.Y.Z.fap` to the GitHub release for a `v*` tag. A
Flipper build failure never blocks the desktop release.
