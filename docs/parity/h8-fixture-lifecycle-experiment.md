# H8 owned Notepad fixture lifecycle experiment (November 15, 2026)

This change tests one bounded hypothesis: closing the completed Notepad fixture between H8 trials may leave a foreground handoff gap while Murmur restarts for the next hotkey. It does **not** establish the cause of a missed guard probe or of any text mismatch.

The earlier H8 run `/tmp/murmur-desktop-43771898733` missed probe 8 between closing the control Notepad and spawning Murmur for the Alt trial. In `/tmp/murmur-desktop-43767810016`, direct control and Alt insertion were exact, but the non-Alt restart later missed a probe. The latest app-free run `/tmp/murmur-guard-43775841889` observed both Unicode key-up and reserved-key up with the owned A window focused and with `SetFocus(NULL)`; after A closed, external PID 37240 became foreground and the guard correctly stopped with `owner_or_focus_lost` before B. These observations leave the H8 lifecycle hypothesis open. They are not a reason to relax the guard or run another diagnostic sequence.

H8 now captures each settled trial's screenshot, UI Automation document text, and exact saved file bytes while its Notepad document remains open. `Ctrl+S` and file readback occur only after the delivery wait and settlement. The completed document remains open through the next `ensure()` and through creation and focus of the next owned document. At most three H8 documents exist. Windows 11 may put them in one top-level Notepad window, so reuse is accepted only for a previously owned handle with the newly requested filename active. Before input or saving, H8 verifies the active document. Per-check restoration closes only tabs whose active filename and process ownership are verified; it does not close an arbitrary shared window or kill another process.

The same fail-closed guard runs continuously through H8. Its real-input detection, focus/session requirements, 0.5-second probe deadline, injected-event trace, and exact history/UI Automation/saved-bytes oracles are unchanged. The focused native run at `ee59fa67b054` completed all 46 probes but the no-Alt document and saved bytes were corrupt despite an exact hook stream. This is one run, so the fixture lifecycle hypothesis is still unproven. The [run triage](desktop-43780792202-triage.md) records the evidence and the bounded next comparison; the native release gate remains closed.
